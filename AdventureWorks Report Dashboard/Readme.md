# 🚴 Adventure Works Dashboard | Power BI

## 📌 Overview

The Adventure Works Dashboard is an interactive business intelligence project developed using Microsoft Power BI. It provides insights into revenue, profit, orders, product performance, regional sales, and product returns.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

## 📊 Dashboard Pages

### 1. Executive Overview

- Total Revenue
- Total Profit
- Total Orders
- Return Rate
- Revenue Trend Analysis
- Orders by Category
- Top 10 Products
- Monthly Revenue, Orders, and Returns
- Most Ordered and Most Returned Product Types

### 2. Regional Sales Analysis

- Interactive geographical map
- Regional filters for Europe, North America, and Pacific
- Country-level sales distribution
- Regional performance analysis

### 3. Product Performance Analysis

- Selected Product Analysis
- Monthly Orders vs. Target
- Monthly Revenue vs. Target
- Monthly Profit vs. Target
- Price Adjustment Parameter
- Total Profit vs. Adjusted Profit
- Product Metric Selection
- Return Percentage Trend Analysis
- Automated Report Summary

## 📈 Key Features

- Interactive KPI cards
- Revenue and profit trend analysis
- Product category comparisons
- Geographical sales visualization
- Performance tracking against targets
- Product return analysis
- Dynamic filters and slicers
- Interactive charts and tables

## 💡 Business Insights

- Analyze revenue and profit trends over time.
- Identify top-performing products and categories.
- Compare actual performance against business targets.
- Explore regional sales distribution.
- Monitor product return rates.
- Evaluate the impact of price adjustments on profitability.
